Abrir o sistema
Para usar como aplicativo no celular
  1. Abra esta página no Chrome (Android) ou no Safari (iPhone).
  2. Android: menu ⋮ e Adicionar à tela inicial.
    iPhone: botão de compartilhar e Adicionar à Tela de Início.
  3. Use o ícone criado. Ele sempre leva ao sistema.

Câmera e galeria (medir salto pelo vídeo) funcionam quando o sistema abre pelo navegador.

Quem não foi convidado verá a tela de acesso negado.
